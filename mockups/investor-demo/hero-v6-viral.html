Built for every role on the team
One tool. Three different superpowers.
Designer
See it before it ships.
Every mockup, screenshot, and HTML prototype your agent generates lands in Platter instantly. Approve in one click. No more hunting through folders or waiting for a developer to share a link.
"I approved 12 variants in the time it used to take me to find one file."
Developer
Claude waits. You decide.
Add one MCP command and your agent blocks mid-session for human sign-off. No more running code nobody wanted. Decision history feeds back into the next prompt automatically.
"Cut my reverting-bad-UI time by 80%. The agent just stops and asks now."
Planner / PM
Review on a link. No install.
Press S in Platter to generate a public share URL. Stakeholders approve or reject right in the browser — no app needed. Decisions sync back automatically and unblock the agent.
"I reviewed 8 mockups on my phone during standup. Agent shipped the winner."
How it works
Set it up in 60 seconds.
01 — Watch
Auto-indexed
Platter watches ~/github/*/mockups and any folder you add. No setup per project. Files appear the instant they're written.
02 — Block
Claude waits
The agent calls present_mockups() via MCP and pauses. You review in Platter, approve or reject, and the agent continues with your feedback baked in.
03 — Share
Share to anyone
Press S to generate a public link. Teammates review in any browser — no Platter install. Verdicts sync back automatically.
