Made for the
quiet review.

Platter is a Mac desktop app that watches the folders where Claude and its agents drop mockups, screenshots, and PDFs — then surfaces them in a Pinterest-style gallery. It also exposes an MCP server so Claude can hand a set of mockups to the human and block until you approve, reject, or rank them.

Direction → editorial gallery · cream paper, ink, vermilion accent · Instrument Serif italic for moments · SF body for native Mac feel.
