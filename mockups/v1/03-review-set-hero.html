Editorial gallery

Asset review is a moment of judgment. A critic at a print room. An editor on a contact sheet. Not a file manager, not a chat sidebar.

Type

  • Display — Instrument Serif (italic). Used sparingly: moments.
  • Body — SF system stack. Authentic Mac feel.
  • Mono — JetBrains Mono. Paths and code only — a signal, not decoration.

Color

Paper #F4EFE5 — warm off-white. Not pure white; pure white reads digital.

Vermilion #C9472A — the single brand accent. Italian print-shop ink, archival stamp. Considered craft, not tech-startup.

Sage #6E7F58 for approve, brick #A04428 for reject.

Motion

  • One orchestrated reveal per screen. Staggered, never simultaneous.
  • Hover lifts are tiny: 1–2px translate.
  • Decisions are deliberate. 200ms fill — fast enough to feel responsive, slow enough that you don't accidentally stamp.

Departures from HIG

Italic Instrument Serif for the prompt during review. Custom pill-shaped decision buttons in display type, not OS controls — a system button would erase the gravity of the moment.
